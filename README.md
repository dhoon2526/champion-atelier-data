# 챔피언 아틀리에 · 공개 설정 JSON

사용자가 창작한 챔피언의 외형, 성격, 배경, 관계, 스킬, 대사·연출과 확정·미정·보류 상태를 원문 그대로 제공하는 읽기 전용 공개 자료입니다.

- `champions.json`: 별도의 정적 JSON 파일. 원본 아틀리에 서버를 거치지 않고 GitHub에서 읽습니다.
- `index.html`: JSON 파일로 연결하는 정적 안내 페이지. 편집 기능이 없습니다.
- `scripts/sync.py`: 원본의 공개 설정만 내려받아 허용된 필드인지 검증한 뒤 JSON을 교체합니다.
- `.github/workflows/publish.yml`: 기본 5분 주기(실제 실행 시각은 GitHub Actions 사정에 따라 늦어질 수 있음), 수동 실행 또는 저장소 변경 시 최신 JSON을 동기화하고 GitHub Pages에 게시합니다.

원본 편집 사이트의 계정 정보, 인증 정보, 작업 이력, 편집 API, 이미지 파일은 포함하지 않습니다. 미정·보류는 확정 설정으로 해석하지 않습니다. 챔피언 설정은 기존 비공개 아틀리에에서만 편집합니다. 원본 공개 데이터 사이트가 비공개로 전환되거나 조회에 실패하면 작업은 실패하며, 마지막으로 성공한 정적 파일을 유지합니다.

창작 설정의 권리는 원저작자에게 있습니다. Riot Games 비공식 창작 프로젝트입니다.
